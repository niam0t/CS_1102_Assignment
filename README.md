# Quiz CLI

A Java program which simulates a simple Quiz game as an assignment of CS1102
course.

- [x] Includes 5 multiple-choice question
- [x] Options are labeled as A, B, C and D
- [x] Prompts the user for typing with the corresponding letter (A, B, C, or D).
- [x] Keeps tracks of correct responses by comparing with the correct answer
- [x] computes and shows final score as percentage at the end
- [x] Uses `if`, `switch` to handle user input
- [x] Includes necessary comments and appropriate names

## How to

1. Compile

```shell
# from src/
javac -d ../out Main.java
```

2. Run

```shell
# from inside out/
java Main
```
